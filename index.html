How it works

      

        

          
1

          
Bring your own keys

          
Open Settings and paste an API key for your AI provider (e.g. OpenRouter). Optionally add a LinkedIn API access token. Everything is stored only in a cookie in your browser.

        

        

          
2

          
Paste a LinkedIn URL

          
Enter the profile or company URL of the person or organization you want to vet. LinkedInGuardian parses the URL and fetches public data.

        

        

          
3

          
AI analyzes the signals

          
The language model reviews the profile text and recent posts for classic scam patterns: unverifiable claims, income promises, fake authority, urgency tactics and more.

        

        

          
4

          
Get a 1–10 trust score

          
You receive a transparent rating with red flags, green flags, cited evidence and a plain-language verdict you can act on.

        

      


      

        Important: LinkedInGuardian is an assistive tool. The AI assessment is an opinion based on public signals — not a fact-check and not a legal judgment. Always do your own due diligence. See the FAQ and the disclaimer.
      

    

  


  
  

    

      
FAQ


      

        Where are my API keys stored?
        

          
Only in a first-party cookie in your browser (lg_settings), optionally encrypted with a master password using AES-GCM via the Web Crypto API. Keys are sent exclusively from your browser to the AI provider you chose. This site has no backend and stores nothing.

        

      


      

        Which AI providers are supported?
        

          
Any OpenAI-compatible chat completions endpoint works out of the box: OpenRouter, OpenAI, Groq, Mistral, local LLM servers (LM Studio, Ollama, llama.cpp) — plus native adapters for Anthropic and Google Gemini.

        

      


      

        Does the LinkedIn API work from a static website?
        

          
Not directly. LinkedIn's official APIs require OAuth 2.0 with a registered application and a server-side token exchange, and they don't send CORS headers to browsers. LinkedInGuardian therefore supports three modes:

          
    
            
  • Public URL mode (default): the AI provider fetches public information about the profile from the web. No LinkedIn key needed.
    • 
            
  • LinkedIn token mode: if you have a valid OAuth access token (e.g. from your own app), it is used to call LinkedIn endpoints that permit it.
    • 
            
  • Proxy mode: point LinkedInGuardian at your own CORS proxy that injects your LinkedIn credentials server-side.
    • 
          

        

      


      

        What does the 1–10 score mean?
        

          
1–2 = strong scam indicators · 3–4 = multiple red flags, high caution · 5–6 = mixed signals, verify claims · 7–8 = mostly credible, minor gaps · 9–10 = consistent, verifiable professional presence. The score is the AI's weighted judgment across signals like claims verifiability, posting behavior, engagement authenticity and language patterns.

        

      


      

        Can I use this to check my own profile?
        

          
Yes — many people run themselves through the checker to see how their profile reads to a skeptical potential client.
